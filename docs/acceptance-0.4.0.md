## 界面与轨迹

主代理在真实 Electron 中打开成员、试演、主聊天轨迹及原始请求详情。已确认切换页签保留试演输入草稿，侧栏没有横向溢出。已完成的原生试演在界面中显示两个方案各两轮正文；选择第二轮轨迹可看到同一试演 Session 内的 6 个实际模型请求和工具结果，能打开请求详情。

修正了两处真实集成问题：离线轨迹曾将完整 DSH 客户端模块工厂打包两次，导致消息页不能注册；现在从已有模块注入投影类。详情的响应式规则原先按整个窗口宽度判断，在宽窗口的窄工作区中仍被挤窄；现在按轨迹容器宽度切换为覆盖详情。没有复制原生执行日志或重写调度。

试演重试可能重新建立根 Session：此前已经提交的轮次仍保留独立轨迹入口，并作为后续请求的历史输入；不会把旧 Session 的执行伪装成新 Session 中再次发生的请求。

## 已知边界

- Token 预算只信任实际用量报告。在途请求可能超过阈值；取消或中断而未拿到完整报告时，启用 token 上限的原任务不能继续请求模型。已知用量的失败可明确从检查点重试。
- 试演附件已复制到独立空间，请求详情保留实际附件引用；当前共享离线详情不额外提供图片缩略图查看器。
- 实际 profile 冷启动存在 4 条 DSH 通用工作区尝试恢复 `eleckoi-default` 的 warning（该名称未注册），以及开发版 Electron 的 CSP warning；产品聊天及 Team 工作区已成功加载，控制台无 JS error。此次未改写正式会话绑定来消除通用工作区的历史恢复提示。
- 字段/关键词记忆检索不调用模型，不提供向量搜索或自动评分。
