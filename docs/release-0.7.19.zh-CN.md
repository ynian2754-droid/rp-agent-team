# RP Agent Team 0.7.19 更新说明

公开仓库此前的版本为 0.7.2。这次同步 0.7.3 至 0.7.19 的本地开发成果，安装包面向使用对应 Windows 宿主补丁的电子爱。

## 作者参数和预设

- 一个作者选项可以选择本轮的有效成员，并整段替换仍启用成员的提示词。宿主先应用替代提示，再展开其中的普通参数标记。保存后下一轮生效。
- 参数页预览有效成员和提示词替换；停用成员的交接、触发来源和权限会从本轮配置裁掉。切回时恢复作者原有成员配置，可继续使用此前的状态和记忆。
- 「经历」增强版 0.3.19 提供「完整协作」「专注续写」以及两个独立开关。「自主生长」让角色有自己的行动，「因果生变」让已在场的情节按具体条件发展。 [预设与使用说明](https://github.com/ynian2754-droid/rp-agent-team-presets/blob/main/LIVED_HISTORY.zh-CN.md)

## 运行、核验和状态

- 请求跳数只计算一次，回执和状态的校验反馈带具体路径。交接可以引用原文，避免成员多次重抄。同一轮的独立交接可以并发，合法终结回执能及时结束子轮。
- 世事先登记用户刺激、派发调卷，并行准备已经确定的环境变化。调卷选择证据，宿主按知情范围投递材料。推演从授权的编号中选依据，在同一份回执提交言行和状态增量。单人调卷路径由宿主完成派发、重试、核验和交回。
- 正文并行经过事实与用户控制权核验、知情与呈现核验。核验各自只看本次材料，宿主合并意见。双路通过时原样发布，退回后由执笔修订。台词里陈述的事实须有独立依据。
- 编年按已发布的原文批量记账。世事追加新事件与编年更新旧记录可以在同一轮进行。宿主按实际终稿核对新事件的呈现状态，并通过正式回执提交正文和状态。

## 安装

下载对应的插件包，使用相应的宿主补丁，在 DSH 插件管理器导入后重启。预设单独下载并导入「角色团队 → 预设」，再应用到需要的聊天。 [安装与迁移](install-guide.zh-CN.md) · [宿主补丁](../host-patch/README.md) · [逐版本变更](../CHANGELOG.md)
