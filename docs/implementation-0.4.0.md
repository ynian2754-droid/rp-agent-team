## Shared configuration

Keep schemaVersion 2. New optional Team fields: authorParameters (array), memory={collections:array}; optional execution.budget. Do not add defaults to old config exports when absent. MinimumPluginVersion 0.4.0 for exports using these fields/new triggers. Existing V1->V2 migration remains.

Budget shape: {maxRequests?:positive integer,maxReportedTokens?:positive integer,maxElapsedMs?:positive integer}; absent disables each bound. Stop/discard on exhaustion; local Team delivery excluded. Trial per-turn defaults 32/64000/180000, task defaults 64/128000/600000. llm/stream GenerateOptions includes sessionId, turn, step, purpose; count exact owned invocation before downstream dispatch; include scheduled/nested/compaction. Actual provider usage only, stable request identity, no double tally. Missing usage with an enabled token threshold blocks subsequent dispatch and fails run. In-flight reported usage may exceed threshold. Ordinary RP outside owned Team sessions unaffected.

New triggers (root implements validation, Luna implements runtime):
- {type:'periodic',id?:stable string,every:positive integer,offset?:nonnegative integer,cooldownTurns?:nonnegative integer}; matches userTurnOrdinal>=offset and (ordinal-offset)%every===0; default offset0.
- {type:'state_changed',id?:string,namespace,path,cooldownTurns?}; true only for a known before/after unequal value or known missing/present transition. Reads need state ACL; no historical-value guessing.
- {type:'message_received',id?:string,from?:string[],messageTypes?:string[],topic?:string,cooldownTurns?}; default only ordinary message. Message types message/request/handoff_result; topic optional author string. Existing message/request send tools accept topic; stored envelopes retain it. Check actual reception/context ACL; merge a request/handoff's existing activation rather than enqueue duplicate.
- {type:'keyword',id?:string,keywords:nonempty string[],match?:'any'|'all',caseSensitive?:boolean,cooldownTurns?}; any, case-insensitive default, simple substring matching, requires visible current_input text. No arbitrary code/regex.
Optional cooldownTurns/id on old triggers also supported. Trigger ID omitted uses stable current config+agent+trigger-index identity; reorder/config change resets that identity. Cooldown based on actual start in a committed run; explicit retry bypasses cooldown but not limits. Scheduler ordinal is active-branch user input count, not native event turn or wall time. Root adds userTurnOrdinal/inputMessageId to captured snapshot if needed. Commit/rewind lifecycle owns cooldown markers; no background models. Author edits are evaluated next explicit run.

Author parameter declaration: {id,name,description?,type:'text'|'number'|'boolean'|'choice'|'agent'|'model'|'state',default?,options?:[{label,value}],valueSchema?,bindings:[{target:{kind:'agent',agentId,path}|{kind:'team',path}|{kind:'state_default',namespace,path},mode:'set'|'text',valuePath?:JSONPointer}]}. Mode text replaces literal {{param:ID}} in an existing string; text parameter only; no eval. Targets are editable config fields, excluding IDs/schemaVersion/credentials/history/parameter declarations. Stable agent reference, not agents array index. state_default refers an existing definition by namespace/path. Model value inherit or {provider,model}; state value {namespace,path}; agent value stable agent ID. Validate resulting full config and references. Binding to state/permission fields can change authority but changes must be shown, never grant implicitly.

Export normalizeAuthorParameters(value,agents,definitions); resolveAuthorParameters(config,values) => {config,values,changes,sourceHash,resolvedHash}; defaults resolved only when no supplied value; invalid/missing required values error. Module may import normalizeTeamConfig/teamError at call time via normal ESM cycle, no top-level normalization calls. ConfigStore get/save records expose parameterValues (map) separate from config; save missing parameterValues preserves previous values for still-existing declarations. Runtime resolves once before freezing, saves template+values+resolved hash in run metadata. Root Remote ConfigInput and config save wiring add optional parameterValues. Export/library stores declarations/defaults, not conversation values. Components remap all bindings, default agent/state refs and textual parameter tokens consistently; retain explicit external ports.

Memory config: {collections:[{id,name,description?,namespace,path}]}; unique IDs, namespace/path must bind declared array state. Records: {id,content,createdAt,updatedAt?,active?:boolean,people?:string[],tags?:string[],source?:string,perspective?:string,confidence?:number,...author fields}; no fixed fact/belief agent or automatic correction. Existing declared valueSchema may add restrictions. Export normalizeMemoryConfig(value,agents,definitions), pure search/update helpers, and registerMemoryTools({...registerTeamTools args}) returning disposer. Tool names rp_team_memory_search/add/update/archive/restore; collectionId is authoritative config binding, expectedVersion on mutations. Search only ACL-redacted rows/fields before filters, sort or counts. No model calls. Require state output authority for mutations, preserve hidden fields on update, CAS/no guessed history; stage through StateStore and scheduler.notify then persist and trace. Expose parent author operations through root's existing getState/applyStateEdit; do not bypass receipt/CAS.

## Trials

createTrialApi({ctx,...runtime.authoring,readState,getOptions}) returns methods plus dispose. Worker lives in separate hidden process with its own environment, product DB/profile/session/plugin/workspace/media paths; no Object.assign(process.env) in main host. Dependencies can reuse immutable installed bundles/cache, never write actual profile. Runtime code reused unchanged except agreed configurable hooks, no copied scheduler. Host helper freezes only selected character/conversation/runtime/state/preset/attachment material and creates trial seed through product APIs; never copy entire actual DB or write Session JSONL by hand. Import seed history through official native local delivery if native history is required; no fictitious model/token events. Trial root is distinct and carries scopeId; minimal real native fixture proves seed, request, flush and commit before expanding UI.

Scenario {id?,name,steps:[{id?,inputText,assertions?:array}],initialState?:[{namespace,path,value}],snapshotId?}. Assertion {type:'body_contains'|'body_not_contains'|'single_output'|'state_equals',text?,namespace?,path?,value?}. Inputs are authored, not generated. Two variants max: {id?,label,config,parameterValues?}; same frozen seed, independent state/history, sequential variants and sequential turns. One active trial task per profile; getStatus independent from pane mounting. Unknown outcome never auto-resubmits/reruns. Retry starts after confirmed last committed checkpoint, preserving completed turns. Drain cancel on plugin shutdown. Selecting a result only returns config+parameterValues to draft.

Public JSON-object APIs (root owns Remote/types/manifests/generated contract): list/get/save/deleteTrialScenario; exportTrialScenario({scenarioId,includeSnapshot:false})/importTrialScenario; freezeTrialSnapshot({conversationId}); startTrial({conversationId,operationId,scenario,variants,allowTrustedTools:false,budget?,turnBudget?}) -> {trialId,status,scopeId}; listTrials({conversationId}); getTrial({trialId}); cancelTrial({trialId}); retryTrial({trialId,operationId}); getTrialTrajectory({trialId,variantId,runId,cursor?,limit?}) -> {native:{events,executions:[{runId,association,events}],runs},sourceSessionId,hasMore,cursor}; the Client projects these actual native facts using the ordinary assembler and renders the shared trajectory view; compareTrial({trialId}) -> variant body/state/member/time/actual usage results. Parameter API previewParameters({config,parameterValues}) -> resolved result without persistence; apply values via existing saveConfig. Methods can return direct promises and root wraps validation only once.

Scenario export defaults authored steps/assertions only; source history/attachments/state require explicit includeSnapshot, credentials always omitted. No caller-provided filesystem paths. No actual state/model mutation for scenario saves/freezes/options. External trusted tools default off even if preset trusts them; explicit per-task choice required and external effects not claimed isolated. Normal managed tools use only copied workspace/media and scoped state. Snapshot/worker/model secrets never enter logs/export/Remote.
